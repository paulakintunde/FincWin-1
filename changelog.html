What's new in FincWin

Every release, documented as it ships. Sorted newest first.

v2.8 June 2026 New
  • NewPWA install banner: Smart install prompt above the top bar — appears on first visit and dismisses permanently once installed or declined.
  • FixAchievement badge displacement: Badges were misaligning in the gamification panel after a page refresh. Now stable on all screen sizes.
  • FixPIN on every refresh: Encrypted users were being asked for PIN on every page load. Root cause was non-extractable DEK; resolved — PIN now fires correctly on session open only.
  • FixDemo profile investment values: Investment balances in demo profiles were displaying as zero due to a field name mismatch. Corrected.
  • ImproveDashboard layout: Smart Insights moved to the left column below Monthly Net Flow chart — better visual hierarchy and context.
v2.7 May 2026 New
  • NewAI coaching (BYOK): Connect your OpenAI or Anthropic API key and ask questions about your own financial data. All conversations go directly from your browser to the AI provider — FincWin never handles the content.
  • NewHealth score v2: Rebuilt the financial health score with six weighted dimensions. Score now updates in real time as data changes and shows per-dimension breakdown.
  • NewLifetime plan: One-time $149 payment for permanent Pro access. No annual renewal, no price increases.
  • ImproveCSV import (Pro): Column mapping step added to handle bank-specific CSV formats. Now supports date format selection and debit/credit split columns.
  • ImproveSavings goals: Added deadline field and monthly contribution calculator. Goals now show whether current pace is on track for target date.
  • FixMulti-currency display: Currency symbol was occasionally switching on dashboard refresh for users with multiple income currencies. Fixed.
v2.6 April 2026 New
  • NewGamification — achievements v2: 40+ achievements across 6 categories. XP system, level progression, and achievement panel in the dashboard.
  • NewInvestment tracking: Added 6 asset types (stocks, ETFs, crypto, bonds, real estate, retirement). Portfolio view with total value and per-asset performance.
  • NewBiometric unlock: WebAuthn-based fingerprint/Face ID unlock on supported devices. Works alongside PIN as an alternative.
  • ImproveLoan payoff planner: Added per-loan payoff date display, total interest projection, and comparison table between snowball and avalanche methods.
  • FixGoogle Drive backup: Drive auth token was expiring silently. Backup now detects expired tokens and prompts re-auth before backup attempt.
v2.5 March 2026 Improve
  • NewMulti-currency support: Set a base currency, log income and expenses in any currency with exchange rate entry, view consolidated totals in base currency.
  • ImproveEnvelope UI: Redesigned budget envelopes with animated progress bars, remaining amount display, and colour indicators (green / amber / red) based on percentage used.
  • ImproveIncome frequency: Added semi-monthly as a 5th income frequency alongside weekly, biweekly, monthly, and custom.
  • FixOffline sync queue: Transactions logged offline were occasionally duplicating on reconnect. Resolved with idempotency key on the sync queue.
v2.0 January 2026 Major
  • NewComplete UI redesign: New design system with Hanken Grotesk + Instrument Serif, sage colour palette, and refined data visualisations.
  • NewAES-256 encryption: Optional full encryption of local data with a PIN-derived key. Drive backups encrypted end-to-end.
  • NewPro plan launch: $39/year Pro with CSV import, loan payoff planner, AI coaching, and full investment tracking. Free plan remains unlimited on core features.
  • NewLoan snowball/avalanche: Multi-loan payoff planner with strategy comparison and real-time extra payment modelling.
