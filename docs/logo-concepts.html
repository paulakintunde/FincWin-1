FincWin Lettermark Concepts

Twelve directions for a distinctive lettermark built from the brand initials — F, W, or the FW monogram — each leaning on the product story: finance that you win at. Pick one to replace the current text logo in the app topbar.

Wordmark: FincWin Typeface: Instrument Serif Accent: Sage #5A6E3F Format: Inline SVG (themeable via currentColor)

How to read & choose

  1. Each concept is shown in three real contexts: light chrome, dark mode, and on the accent fill (app-icon use).
  2. Below each mark is its wordmark lockup — how it pairs with the “FincWin” text in the topbar.
  3. All marks are single-color vector and inherit currentColor, so they adapt to every theme (sage, glass, clay, dark) with zero extra assets.
  4. Reply with the number you want (e.g. “Go with #4”). I’ll cut the final SVG, wire it into index.html / layout.css, and add a matching favicon + PWA icon.
